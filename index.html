Supabase Bulut Bazasi (PostgreSQL)

Bulutli Baza Imkoniyatlari:

Supabase ulanganda barcha yaratilgan guruhlar, o'quvchilar ro'yxati, prompt topshiriqlari va AI baholari to'g'ridan-to'g'ri bulutda saqlanadi va real vaqtda har qanday kompyuter yoki telefonda yangilanadi.

Supabase boshqaruv panelidagi: Project Settings → API → Project URL
Supabase boshqaruv panelidagi: Project Settings → API → Project API keys → anon public
Tezkor 3 qadam: 1. supabase.com saytida yangi bepul loyiha oching.
2. SQL Sxemani oling va Supabase SQL Editor bo'limida ishga tushiring.
3. URL va Anon kalitni bu yerga kiritib, "Ulash va Saqlash" tugmasini bosing!

Supabase SQL Sxemasi (Jadvallar va RLS)

Ushbu SQL kodni Supabase boshqaruv panelidagi SQL Editor → New Query bo'limiga qo'ying va Run tugmasini bosing. Bu groups, users, assignments va submissions jadvallarini avtomatik yaratadi. 

-- 1. GURUHLAR JADVALI
CREATE TABLE IF NOT EXISTS public.groups (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT DEFAULT '',
  schedule TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. FOYDALANUVCHILAR VA GURUH A'ZOLARI
CREATE TABLE IF NOT EXISTS public.users (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  role TEXT NOT NULL DEFAULT 'student',
  title TEXT DEFAULT '',
  email TEXT DEFAULT '',
  phone TEXT DEFAULT '',
  group_name TEXT DEFAULT '',
  avatar TEXT DEFAULT '',
  joined_at TEXT DEFAULT '',
  subjects JSONB DEFAULT '[]'::jsonb,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. PROMPT VAZIFALARI
CREATE TABLE IF NOT EXISTS public.assignments (
  id TEXT PRIMARY KEY,
  subject TEXT NOT NULL,
  subject_badge_class TEXT DEFAULT 'badge-role',
  target_group TEXT DEFAULT 'Barcha guruhlar',
  title TEXT NOT NULL,
  description TEXT NOT NULL,
  deadline TEXT DEFAULT '',
  deadline_display TEXT DEFAULT '',
  max_score INT DEFAULT 100,
  difficulty TEXT DEFAULT 'Boshlang''ich',
  criteria TEXT DEFAULT '',
  sample_solution TEXT DEFAULT '',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 4. TOPSHIRILGAN PROMPTLAR VA AI TEKSHIRUVLARI
CREATE TABLE IF NOT EXISTS public.submissions (
  id TEXT PRIMARY KEY,
  assignment_id TEXT NOT NULL,
  student_id TEXT NOT NULL,
  student_name TEXT NOT NULL,
  student_avatar TEXT DEFAULT '',
  student_group TEXT DEFAULT '',
  submitted_at TEXT DEFAULT '',
  answer_text TEXT NOT NULL,
  attached_file TEXT DEFAULT NULL,
  external_link TEXT DEFAULT NULL,
  status TEXT DEFAULT 'graded',
  ai_report JSONB DEFAULT '{}'::jsonb,
  teacher_note TEXT DEFAULT '',
  teacher_approved BOOLEAN DEFAULT TRUE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- XAVFSIZLIK: RLS va Ommaviy kirish ruxsati (Anon key uchun)
ALTER TABLE public.groups ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.users ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.assignments ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.submissions ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Public groups" ON public.groups FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Public users" ON public.users FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Public assignments" ON public.assignments FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Public submissions" ON public.submissions FOR ALL USING (true) WITH CHECK (true);
